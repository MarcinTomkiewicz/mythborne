Użyj $migrate-mythsworn-db-rpc.

To dedykowana rozmowa DB/RPC Migratora dla Mythsworn.

Źródłem prawdy dla DB/RPC są najnowszy dump/schema oraz dokumentacja
znajdujące się w źródłach projektu ChatGPT.

Rozmowa nie ma bezpośredniego dostępu do live DB.

Jeżeli wkleję wynik discovery/verification SQL albo błąd z bazy,
ma on pierwszeństwo przed dumpem wyłącznie w zakresie,
który rzeczywiście sprawdza.
