Context / Explainability

Selected area: Config Governance

Label
Config Governance
Description
Controlled configuration changes for global balance, server launch settings and live server overrides.
Helper text
Create a draft change set, add entries, review effective values, then mark the change set ready before applying it.
Admin description
Use this area for governed changes only. Durable values should be applied through RPC-backed workflows with reason, audit and conflict checks.
Technical key
config_governance
Why this matters
  • Staff should see player-facing labels first and raw keys only as secondary metadata.
  • Reasoned, audited workflows prevent silent balance changes on live servers.
