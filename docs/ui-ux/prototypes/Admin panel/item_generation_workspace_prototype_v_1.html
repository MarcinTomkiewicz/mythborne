End-to-end balance flow

Ten workspace ma pokazać pełną ścieżkę: edit → draft diff → preview → mark ready → apply.

1. Edit curve fieldChange base_value, growth, rounding or increment inside active draft.
2. Draft diffEntry appears in Balance Draft with live/proposed values.
3. PreviewLuck Lab compares live/proposed bucket sequence and generated samples.
4. Mark readyBlocked if conflict/missing reason exists.
5. ApplyAtomic apply promotes final proposed values to live.
IA note
  • Item Generation jest Game Balance workspace, nie Formula Library ani raw item table browser.
  • Bucket profiles są krzywą/generatorem budżetów wartości: bucket_count, base_value, linear_growth, growth_factor, rounding_step, minimum_increment i generated bucket sequence.
  • Bucket value curve ≠ drop chance / rarity chance. Żeby ocenić realny drop power, trzeba patrzeć też na item bases, quality multipliers, affix weights, formula hooks i Preview / Luck Lab.
  • Catalog definitions i balance tuning są rozdzielone wizualnie, nawet jeśli produkcyjnie współdzielą route.
  • Formula expression/assignment edit linkuje do Formula Library. Domain preview może pokazać wpływ, ale nie duplikuje pełnego edytora formuł.
  • Wszystkie durable zmiany idą przez active draft / governed workflow. No direct live edit.
  • Preview z draft overlay nie wpływa na live gameplay.
  • Missing metadata to quality gap: raw label/helper/admin description/source explanation.
