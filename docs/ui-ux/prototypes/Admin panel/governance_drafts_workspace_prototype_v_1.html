Lifecycle help / IA appendix

Lifecycle jest pomocą, nie główną powierzchnią pracy. Operator wraca tu tylko, gdy potrzebuje wyjaśnienia procesu.

  • Edit draft: proposed values, live gameplay bez zmian.
  • Preview context: admin/sandbox może zobaczyć Live + draft overlay.
  • Mark ready i apply są niedostępne, jeśli są blockery.
  • Atomic apply: partial apply nie istnieje w MVP.

IA appendix: Governance nie jest route inventory. Active Draft jest głównym flow; Config Registry, Formula Library i Audit Support są linkami/sub-workspace’ami albo osobnymi prototypami.

  • Raw keys mogą być secondary metadata, ale nie primary label.
  • Missing metadata oznacza realny quality gap: label/helper text/preview metadata.
  • Formula Library jest dla całej gry, nie tylko podstroną Game Balance.
