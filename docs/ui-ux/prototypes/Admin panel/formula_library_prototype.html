IA note
  • Formula Catalog jest pierwszym bytem: formuły są reusable library items.
  • Editor jest widoczny, bo Formula Library centralnie obsługuje expression/metadata changes. Save to active draft tworzy lub aktualizuje draft entry; live zmienia się dopiero po apply.
  • Assignments są osobnym obszarem: target → formula, z current/proposed/override/conflict. Główny editor pokazuje summary; pełna lista należy do Assignments Explorer/drawera/tabeli z filtrami.
  • Where-used musi być widoczne wcześnie jako impact summary, bo expression edit może wpłynąć na kilka targetów, workspace’ów i runtime/read-model surfaces.
  • Where-used powinno pochodzić z DB/RPC read modelu: assigned targets, global/default assignment, entity overrides, active draft changes, impacted workspaces, preview links and runtime/gameplay impact.
  • Assignments mówią target → formula. Where-used mówi gdzie formuła realnie wpływa na grę/runtime/workspace’y. To powiązane, ale nie to samo.
  • Domain workspaces pokazują domain-specific preview i linkują do Formula Library dla expression/assignment edit, np. „Open full curve in Formula Library”.
  • All changes go through active draft/governed workflow. No direct live edit.
