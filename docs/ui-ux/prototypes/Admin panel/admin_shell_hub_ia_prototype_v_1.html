Implementation notes / IA appendix

Materiał dla projektowania i późniejszej implementacji. Nie jest głównym UI operatora.

Show IA decisions and route placement reference
Combat Balance → Game BalanceDefinicje przeciwników, combat content i formuły są balansowaniem gry. Sandbox ma tylko symulatory i debug.
Reward Profiles → Exploration & PvEReward Profiles są główną częścią PvE reward wiring. Game Balance może mieć cross-link, ale primary home jest przy Trials/Encounters.
PvP diagnostics → de-emphasizedDopóki player-facing PvP nie jest dużym modułem UI, diagnostyki PvP nie dominują top-level admin hubu. Są w diagnostics/moderation/combat cross-linkach.
Reports & Notifications → workspaceRaporty i notyfikacje mają własną operator-facing czytelność. Audit pozostaje cross-cutting support, nie trzecią równorzędną rzeczą w nazwie.
Server Events → Server OperationsServer Events są operacyjnym stanem serwera, nawet gdy wpływają na gameplay. Nie są zwykłym Game Balance.
