Registry quality checks

Draft overlay consistency2 configs already have active draft entries.

IA note
  • Config Registry odpowiada: czym jest config definition/value, jaka jest wartość live/effective, czy aktywny draft proponuje zmianę i jaki jest governance scope.
  • Przykłady są illustrative. Produkcyjnie lista musi pochodzić z DB-backed config registry/read models.
  • Relacyjne balance entities — bucket profiles, qualities, formulas, assignments — żyją w odpowiednich workspace’ach albo w Active Draft Diff, jeśli są częścią draftu.
  • To nie jest raw JSON/table browser. Technical key jest secondary metadata.
  • Zmiana configu nie mutuje live bezpośrednio. Trafia do active balance draft albo odpowiedniego governed change workflow, jeśli taki path istnieje.
  • Missing metadata to realny quality gap: label/helper/admin description/source explanation.
